# Frontend design contract

Table Tides is an overhead banquet floor, not a dashboard. The first viewport is a linen room plan with sculptural oval tables, orbiting chairs, loose place cards, a pencil-marked host folio, and a slim service timeline. Linen cream, oxblood, plum, celadon, and candle gold define a festive editorial world. Components use paper cards, wax seals, chair tabs, pencil lines, and tablecloth shapes. Motion consists of card drift, chair pull, place-card settle, conflict wobble, and candle finish; reduced-motion mode removes it. The core action is choosing a guest, a physical chair, and a rationale.

The interface must never resemble a workshop, mechanical panel, stage, feed, map, radial instrument, or generic form stack. The floor remains primary on mobile, followed by the host folio. Wallet, contract state, conflicts, selected chair, pending action, and errors remain legible.
